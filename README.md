--Brief Description
  The Gamified Learning Platform is a web-based educational application designed to make learning technical subjects more interactive and engaging through gamification
  techniques. The platform allows students to learn topics, attempt quizzes, earn points, unlock achievements, and track their progress in a fun and motivating 
  environment. The project focuses on improving student engagement and learning efficiency by combining education with game-like elements such as rewards, levels, 
  badges, and leaderboards.

--Technology Stack and Tools Used
  Frontend-HTML5,CSS3,JavaScript,Bootstrap
  Backend-Python,Django Framework
  Database-SQLite3
  Tools & Platforms-VS Code,Git & GitHub

--Features and Functionalities Implemented
  The platform includes several features designed to improve the learning experience of students. Users can register and log into the system securely and access a 
  personalized dashboard that displays their progress and achievements. The platform provides topic-wise technical learning materials along with interactive quizzes 
  containing multiple-choice questions. Students can earn points and rewards after completing quizzes and learning activities. A leaderboard system is implemented to 
  encourage healthy competition among users by displaying rankings based on scores and achievements. The application also includes badge and achievement systems that 
  motivate students to complete tasks and improve their performance. Additionally, the admin panel allows administrators to add, edit, and manage learning content, 
  quizzes, and user activities efficiently.
